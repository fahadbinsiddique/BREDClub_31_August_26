# BREDClub Django Project

A Django-based community and club website with public pages, dashboard content management, contact and volunteer forms, and starter content for quick setup.

## Quick Start

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Initialize the project:
   ```bash
   python setup_project.py
   ```
3. Run the development server:
   ```bash
   python manage.py runserver
   ```
